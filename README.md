# number-theory

### dirichlet.py
A small demo of Dirichlet characters and some nice properties
Gauss' sum, L-functions, empirical verification of some results from the book *Multiplicative Number Theory* by Harold Davenport

### Sieve.cpp
Polynomial manipulation utilities, written using Boost libraries.
Based off of "An Introduction to the General Number Field Sieve" by M.E. Briggs.
